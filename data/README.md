# HIGGS data

Download the official HIGGS dataset from https://archive.ics.uci.edu/dataset/280/higgs. Store the original compressed file locally in `data/raw/` if needed. Do not commit the dataset to Git. The course notebook first streams a subset directly from the official source; record the actual data method in each run. The UCI dataset page states that the data are simulated Monte Carlo events and provides the feature/target description and citation.
