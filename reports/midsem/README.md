# Mid-semester submission area

Put the submitted mid-semester report, slides, and a small manifest of the exact supporting run here. The work should demonstrate the full experimental path on the declared data budget, not just a polished interface.

Required evidence:

- an executed MVP notebook with source, row count, seed, and split;
- Logistic Regression, XGBoost, and MLP comparisons across the required feature groups;
- ROC-AUC, average precision, Brier/calibration, supplemental accuracy, and measured timing where available;
- validation-selected model/threshold choices and one untouched test evaluation;
- a concise limitations section stating that this is simulated HIGGS data, not a discovery analysis.

Use `docs/02_midsem_plan.md` for the complete rubric-aligned checklist.
