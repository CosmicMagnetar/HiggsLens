# Final submission area

Keep the final report, slide deck, and submission manifest here. The checked-in `benchmark_report.md` is a reporting template: replace every `[NOT RUN]` marker only after an actual HIGGS benchmark has completed and its artifacts have been checked.

The final submission should cite the run identifier, data budget, feature group, model configuration, validation-selection rule, frozen test metrics, compute environment, and known limitations. The dashboard supports review of exported artifacts; it does not turn a simulated benchmark into a detector-ready decision system.

Use `docs/03_endsem_excellence_plan.md` and `docs/10_submission_checklists.md` for the final evidence checklist.
